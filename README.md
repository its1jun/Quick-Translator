# 적용 가이드
1. 파일다운
<img width="360" height="105" alt="image" src="https://github.com/user-attachments/assets/c0efaf51-944d-456c-bee1-015e97999a5d" />
에서 install.bat 다운
  
2. 아래 링크 접속
```text
chrome://extensions
```
3. 오른쪽 위 "개발자 모드" 켜기
4. 왼쪽 위 "압축해제된 확장 프로그램 로드" 실행
   `압축해제된 확장 프로그램 폴더`위치:
   ```text
   %USERPROFILE%\Chrome_Extensions\
   ```
